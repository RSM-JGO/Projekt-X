# Architekturentscheidungen

Hier werden abgestimmte Architekturentscheidungen dokumentiert. Beschlossen: 001 technische Grundrichtung, 002 Windows als Entwicklungs- und Serverplattform, 003 Produktregeln für den ersten Ablauf (teilweise ersetzt), 004 Administratorrechte und Projektsichtbarkeit.

Jede Entscheidung benennt Datum, Status (Entwurf, beschlossen, ersetzt), Problem, betrachtete Alternativen, gewählte Lösung, Gründe, Konsequenzen und betroffene Backlogeinträge. Entwürfe dürfen nicht als Benutzerfreigabe behandelt werden.
