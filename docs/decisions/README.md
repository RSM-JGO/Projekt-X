# Architekturentscheidungen

Hier werden abgestimmte Architekturentscheidungen dokumentiert. Aktuell ist noch kein Technologiestack beschlossen.

Jede Entscheidung benennt Datum, Status (Entwurf, beschlossen, ersetzt), Problem, betrachtete Alternativen, gewählte Lösung, Gründe, Konsequenzen und betroffene Backlogeinträge. Entwürfe dürfen nicht als Benutzerfreigabe behandelt werden.
